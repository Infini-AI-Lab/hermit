§What Hermit gives you out of the box

Hermit is an open-source framework with one training loop for harness adapters. Bring your tasks and feedback; choose a learning method or write your own. It provides shared infrastructure for:

  • One Trainer for every method: rollouts, judge feedback, an Evolver step, a checked commit, the next version
  • GEPA, SkillOpt, MetaWorld Model, Harness², Continual Harness and ReHarness; Codex and Claude Code as learner agents
  • Adapters as files in a git tree: inspect every version, roll back, ship the final one
  • Deploy workspaces for Codex, Claude Code or Pi, or export supported contents as a native plugin for compatible hosts
  • Adapter specification checks and versioned updates, with sandboxing for supported learner programs
  • Any model backend by reference: Fireworks, OpenAI, Anthropic, DeepSeek, vLLM, SGLang, Ollama

§Why a harness adapter

NeedAgents meet scenarios their harness was not written for: a new domain, a new tool, a stream of tasks whose rules only show in the feedback. They should keep learning in deployment.
TodayTwo ways to adapt an agent: edit its harness by hand, which does not scale and does not learn, or fine-tune the model, which is expensive, opaque, and tied to one model.
WhyA harness adapter puts the learnable part outside the agent: an instruction file, skills, tools, a world model of the venue. The base stays frozen, the adapter trains from feedback, and the same adapter moves between compatible harnesses.

§Get started

# Python 3.11+ and git
git clone https://github.com/Infini-AI-Lab/hermit.git && cd hermit
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# run the offline training walkthrough
hermit check --config docs/_examples/first_training/run.yaml
hermit train --config docs/_examples/first_training/run.yaml
hermit eval  --config docs/_examples/first_training/run.yaml --adapter final

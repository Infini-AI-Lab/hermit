# Codex learner

The current method guide is [Codex and Claude agent learners](agent.md). It covers requirements, learner-session
behavior, defaults, tool access, and a complete task configuration (CL-Bench poker).

To configure Codex as the **acting agent**, use [Built-in agents](../framework/task.md#built-in-agents).
The acting-agent selector is `agent.name`; `evolver.name: codex` selects the learner.

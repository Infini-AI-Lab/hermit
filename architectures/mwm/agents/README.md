Sub-agents — one prompt per directory, run in a host's seat on a sub-task
the host names. agents/<name>/SPEC.md: first line = when to delegate to
it (the catalog line hosts read); scope / last_confirmed_t / derived_from;
then the prompt. A sub-agent carries the host's tools except the one
that ends the episode; it receives the same package and episode input
the host did, plus this prompt; its final message returns to the host.

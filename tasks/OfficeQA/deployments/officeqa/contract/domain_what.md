It is a corpus of 697 U.S. Treasury Bulletin issues (1939 onward), one
parsed text file per issue, behind a graded question task: each question
asks for a figure or a computation from those documents. Nothing in the
corpus is indexed by question; a full-text index over the documents is the
only lookup.

A correct answer scores 1 (official scorer, numeric tolerance 0); a wrong,
empty or over-long answer scores 0. The score is accuracy alone; search
count, tool calls and time do not enter it.

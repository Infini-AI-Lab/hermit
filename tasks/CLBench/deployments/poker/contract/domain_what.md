It is heads-up Texas Hold'em. The opponent's NAME is given in every hand
header, and the table announces when a different opponent takes the seat.
Nothing else about an opponent is stated anywhere; the record of hands
against that name is the only source.

Stacks reset to 1000 every hand at blinds 5/10, so a hand is
self-contained. The score is average profit per hand in big blinds and it
can go negative.

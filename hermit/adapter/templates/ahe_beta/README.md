# AHE-Beta Codex adapter

The Codex adapter of **Agentic Harness Engineering Beta: Requirement-Centered
Evolution of Agent Harnesses** ([arXiv:2611.24924](https://arxiv.org/abs/2611.24924)):
instructions, skills, helper scripts, roles and hooks evolve from simulated-user
feedback. Codex, the user simulator, task inputs and verifier remain fixed. This
adapter is separate from AHE-Beta's NexAU seed Harness and does not reproduce
that runtime.

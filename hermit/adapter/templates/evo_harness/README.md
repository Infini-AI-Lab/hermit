# Evo-Harness template

The adapter of Evo-Harness ([Wei et al.](https://arxiv.org/abs/2608.15071),
[code](https://github.com/A-EVO-Lab/a-evolve/tree/release/evo-harness)): a harness of skills at two levels, which the
`evo_harness` Evolver updates online. `general/<name>/SKILL.md` are cross-task skills, shown in full in `ADAPTER.md`'s
block; `skills/<topic>--<name>/SKILL.md` are task-type skills, exported to the host and listed by description.

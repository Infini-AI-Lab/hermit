# ACE template

The adapter of ACE, Agentic Context Engineering ([Zhang et al.](https://arxiv.org/abs/2510.04618),
[code](https://github.com/ace-agent/ace)): one context file, `ADAPTER.md`, holding a playbook of bullets with
helpful/harmful counters under sections, which the `ace` Evolver grows by incremental deltas. Supports any host or
pipeline that can put text in front of the agent.

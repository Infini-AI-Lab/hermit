It is an online retailer's order-support desk. A customer writes in — to
cancel an order, change one that has not shipped, return or exchange items
already delivered, or place a new one — and a host must carry the request
out with the desk's own tools, or refuse it. Reference documents are
mounted and searchable. The operating policy behind the desk is not
published; what the desk currently allows is knowable only from requests
that have already been handled and graded.

An episode is one customer message, and it is scored once: a request is
correct when the final database state is the intended one, or when it is
refused with the correct reason code, or when a question is answered
correctly. Rewards are 1 or 0 and arrive per request.

The `Current timestamp` line on the instruction is that request's position
in the stream, counting from one.

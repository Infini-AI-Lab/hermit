# Evolution guide: minimal-shop

This document is for the Evolver. ADAPTER.md is the acting-agent context. This guide is editable core documentation, not a permission policy.

## Structure

- adapter.json declares callable tools and native role sources.
- adapter_tools.py implements memory access and Decimal calculations.
- memory/policies.json contains fictional shop policies with scope and source identifiers.
- agents/ contains the optional memory-scout role.
- ADAPTER.md explains how acting agents use the capabilities.

## Updating

Read evidence/README.md before interpreting its records. Use new evidence to revise applicable policy facts, preserving sources and scope. Update code when a stable computation or parsing operation needs repair. Keep descriptions and schemas consistent with implementation. Do not turn a demonstration policy into an unsupported real-world claim.

All files here may change. Framework-owned MCP transport, generated host configuration, and original evidence are outside this core. Use the granted checks to confirm that exported functions and role references remain usable. Test results and permissions must come from actual framework responses, not assumptions in this README.

# OfficeQA Skill

## Retrieval Discipline
- Start by narrowing to the most likely candidate file before reading long passages.
- Prefer targeted search terms that name the exact entity, period, measure, or table concept from the question.
- After a promising match, read only a small surrounding span and verify it matches the requested year, basis, and unit.

## Evidence Discipline
- Extract the exact value from the retrieved text before doing any arithmetic.
- Keep track of each operand's period, unit, and semantic role so nearby proxy values are not mixed in.
- If the question asks for a transformed or derived quantity, compute only after confirming every operand.

## Final Answer Discipline
- Return the final answer only after one last consistency check against the retrieved evidence.
- Copy the final answer from a checked value, not from an unverified intermediate guess.

[calc-00001] helpful=0 harmful=0 :: For a question asking what percentage is not a specified category, calculate (total obligations minus obligations in the specified category) ÷ total obligations × 100, then round to the requested precision.
[calc-00004] helpful=0 harmful=0 :: Interpret Treasury bond quotations in thirty-seconds: convert A-B to A + B/32 before calculations. Apply simple exponential smoothing recursively to the original USD price series, then convert the one-step USD forecast to DEM.
[calc-00007] helpful=2 harmful=0 :: For the population standard deviation of 12 fiscal-year monthly values, compute the mean μ across all 12 observations, then use σ = sqrt(Σ(xᵢ − μ)² / 12); divide by 12, not 11, and round only the final result to the requested precision.
[calc-00010] helpful=0 harmful=0 :: For a population coefficient of variation, calculate CV = (σ ÷ μ) × 100, where μ is the arithmetic mean of all requested annual values and σ = sqrt(Σ(xᵢ − μ)² ÷ N); round the resulting percentage to the requested decimal places.
[calc-00011] helpful=0 harmful=0 :: For two reported growth rates, calculate the absolute difference as |rate for the later quarter − rate for the earlier quarter|, then round the result to the nearest tenth.
[calc-00013] helpful=0 harmful=0 :: For the coefficient of variation of year-to-year log growth rates, calculate g_t = ln(x_t / x_{t-1}) for each adjacent pair, then compute the arithmetic mean and population standard deviation of the resulting N−1 growth rates; report σ_g ÷ mean(g_t), rounding only the final result.
[calc-00016] helpful=0 harmful=0 :: For a yield-spread minimum, calculate spread for each month as corporate Aa bond yield minus Treasury bond yield, then select the smallest numerical result; do not infer the minimum from a partial table or a visually plausible value.
[calc-00018] helpful=0 harmful=1 :: When a Treasury table reports receipts in millions of dollars and the answer requires nominal dollars, multiply the reported figure by 1000000 and return the resulting unformatted integer.
[calc-00020] helpful=0 harmful=0 :: For questions asking for the smallest gap between two Treasury-bill rates, compute |13-week rate − 26-week rate| for every March issue-date row in the specified table, then select the issue date with the minimum absolute gap.
[calc-00022] helpful=1 harmful=0 :: When converting a Treasury table value reported in millions, add or otherwise calculate using the table's reported numerical values and apply the exchange rate directly; multiply by 1,000,000 only when the question explicitly requires absolute dollars rather than the reported million-scale amount.
[calc-00025] helpful=0 harmful=0 :: For logarithmic growth reported as a percentage between two endpoint values, calculate 100 × ln(final value ÷ initial value), then round only the final result to the requested precision; do not substitute simple percentage change.
[calc-00026] helpful=0 harmful=0 :: For a target observation compared with a reference sample, calculate z = (x_target − x̄_reference) ÷ s_reference, where s_reference = sqrt(Σ(xᵢ − x̄)² ÷ (n − 1)); use only the reference observations to compute x̄ and s, then compare |z| with the stated threshold.
[calc-00028] helpful=0 harmful=0 :: When Treasury receipts are reported in millions of dollars but the answer is requested in billions, divide the reported value by 1,000, then round the converted result only to the requested precision.
[calc-00033] helpful=1 harmful=1 :: For a change in a category's share of an annual total, calculate each year's share separately as (category value ÷ same-year total value) × 100, then subtract the earlier share from the later share; report the result in percentage points and round only the final difference to the requested precision.
[calc-00034] helpful=0 harmful=0 :: For a centered three-point triangular moving average with weights 1:2:1, calculate WMA = (xₜ₋₁ + 2xₜ + xₜ₊₁) ÷ 4. Use the same units for the moving average and comparison value before computing ln(comparison) − ln(WMA); round only the final result.
[calc-00039] helpful=0 harmful=0 :: For a comparison asking how much greater one currency balance was than another across the selected interior observations, compute the requested difference in the table’s stated units as balance of the former minus balance of the latter, and show the row-level values and subtraction before checking the final result.
[calc-00040] helpful=0 harmful=0 :: For two inclusive 13-month periods of monthly nominal sales, collect all 13 observations for each period after combining the specified series, sort each period's values, calculate its median (the seventh value), round each median independently to the nearest million dollars, and return the larger rounded median.
[calc-00042] helpful=1 harmful=0 :: For the geometric mean of N positive monthly outlays, calculate GM = exp((1/N) × Σ ln(xᵢ)); use the nominal-dollar values in consistent units, confirm N equals the number of requested calendar months, and round only the final result.
[calc-00045] helpful=0 harmful=0 :: When comparing average asset shares across two sets of dates, calculate each date's share as (foreign-exchange holdings plus securities) ÷ total assets, average the shares separately for each date set, then take the absolute difference. If CPI-U applies the same factor to every nominal component on a given date, the adjustment cancels in that ratio; round only the final percentage-point difference.
[calc-00047] helpful=0 harmful=0 :: For each calendar year with quarterly real GDP growth rates r1–r4 reported as annualized percentages, calculate GM = (((1+r1/100)(1+r2/100)(1+r3/100)(1+r4/100))^(1/4) − 1) × 100. Compare the unrounded geometric means across all requested years and round only the selected maximum to the requested decimal places.
[calc-00049] helpful=0 harmful=0 :: For a tender-category share, calculate (accepted tenders in the specified category ÷ total bids submitted) × 100, using the same reported units for both values; do not substitute total accepted bids or another tender category as the denominator, and round only the final percentage.
[calc-00051] helpful=2 harmful=0 :: For Pearson correlation between two paired monthly series, use r = [NΣxy − (Σx)(Σy)] ÷ √([NΣx² − (Σx)²][NΣy² − (Σy)²]); include every observation from both inclusive endpoint months, pair values by the same date, and round only the final full-precision coefficient.
[calc-00052] helpful=1 harmful=0 :: For a change from an earlier calendar month to a later month, calculate later-month value minus earlier-month value. Preserve the source table's stated units, such as millions of nominal dollars; a negative result indicates a decrease.
[calc-00055] helpful=2 harmful=0 :: For endpoint values x0 and xn separated by n years, calculate annual decay factor as (xn ÷ x0)^(1/n), CAGR as (xn ÷ x0)^(1/n) − 1, and midpoint arc elasticity as (xn − x0) ÷ ((xn + x0) ÷ 2). Use n only for CAGR and the decay factor; round all requested results only at the end.
[calc-00058] helpful=1 harmful=0 :: For historical-simulation VaR from a small return sample, compute each year-over-year return as (current value − prior value) ÷ prior value, sort the returns ascending, locate the lower-tail p-percentile at position (n − 1) × p using linear interpolation between adjacent observations, and report positive VaR as the negation of that percentile when the percentile is a loss.
[calc-00060] helpful=0 harmful=0 :: For parametric one-tailed normal VaR defined as mean minus z times population standard deviation, compute the arithmetic mean and population standard deviation across all requested observations, apply the supplied z-score directly, take the absolute value of the result when a positive VaR magnitude is requested, and round only the final magnitude.
[calc-00064] helpful=0 harmful=0 :: For the target year's share of total Treasury Notes outstanding across several years, calculate target-year total ÷ (sum of all requested yearly totals). Preserve fractional values reported in millions and round only the final decimal to the requested precision.
[calc-00066] helpful=0 harmful=0 :: For equal-length consecutive periods under the same annualized compound growth rate, project the next period as next value = observed endpoint × (observed endpoint ÷ initial value); equivalently, compute the CAGR over the first interval and compound it for the second interval. Preserve full precision through the calculation and round only the final projection.
[calc-00070] helpful=0 harmful=0 :: For an OLS line y = a + bx on equally spaced monthly observations, compute b = Σ[(xᵢ − x̄)(yᵢ − ȳ)] ÷ Σ[(xᵢ − x̄)²] and a = ȳ − b x̄; evaluate the forecast at the next month’s index and round only the final yield.

This pooled share is not the difference between the first and last monthly shares; round only the final percentage.

## COMMON MISTAKES TO AVOID

[err-00002] helpful=18 harmful=0 :: When an answer requests a single rounded value, do not include the calculation, units, or explanatory prose unless explicitly requested; exact-match evaluation may require only the final value.
[err-00005] helpful=0 harmful=0 :: Do not treat Treasury quotations such as 82-04 as decimal 82.04, and do not smooth already currency-converted observations when the requested forecast is based on the USD bid-price series.
[err-00017] helpful=0 harmful=0 :: Verify the bulletin date, table title, row date, account row, and column heading before copying a value; neighboring trust-account figures can be numerically plausible but answer a different measure.
[err-00019] helpful=0 harmful=0 :: For exact-match questions requesting one rounded numeric result, output only the numeric token; omit units such as “percentage points” even when the prompt describes the result with units, unless the required format explicitly demands a labeled or unit-bearing answer.
[err-00023] helpful=1 harmful=0 :: Do not expand a figure labeled in millions into absolute units merely because the final answer changes currency; after conversion, check whether the magnitude contains an unexplained factor-of-one-million.
[err-00027] helpful=0 harmful=0 :: Do not use the population standard deviation denominator n when the target is being evaluated against a limited reference sample; dividing by n instead of n − 1 understates the reference dispersion and inflates the z-score.
[err-00031] helpful=0 harmful=0 :: Do not guess a graph-feature count from incomplete text extraction or inspect only the first plot; local maxima must be identified visually as genuine changes from increasing to decreasing, excluding endpoints and non-structural visual artifacts.
[err-00032] helpful=0 harmful=0 :: Verify that the cited printed page corresponds to the correct PDF or scan page before analyzing the chart, since viewer page numbers and printed page numbers may differ.
[err-00036] helpful=0 harmful=0 :: Before taking logarithms or applying a trimmed mean, reconcile the selected values with the source label, units, and fiscal-year scope. Numerically consistent calculations based on adjacent annual rows, component values, or a different borrowing measure still answer the wrong question.
[err-00043] helpful=0 harmful=0 :: Do not trust a plausible geometric-mean result when the underlying monthly list has not been reconciled to every month label, Judiciary column, bulletin edition, and unit; a shifted row or misassigned month can preserve internal arithmetic consistency while producing the wrong answer.
[err-00048] helpful=0 harmful=0 :: Do not calculate a plausible geometric mean from one guessed or incomplete year's four quarters when the question asks for the maximum over several years; unverified chart values are insufficient evidence, and every year's quarterly inputs must be sourced and compared.
[err-00054] helpful=0 harmful=0 :: Do not substitute a similarly titled item from another bulletin or infer an original publication month and year from a title or author match. Distinguish the date of the Treasury listing from the date of the item's National Bureau of Economic Research publication, and state that the date is unverified if the bibliographic record cannot be checked.
[err-00056] helpful=0 harmful=0 :: Do not treat midpoint arc elasticity between two outlay values as elasticity with respect to time: unless explicitly requested, do not divide the midpoint percentage change in outlays by a percentage change in fiscal years.
[err-00061] helpful=0 harmful=0 :: Do not substitute historical-simulation percentile VaR when the question explicitly specifies parametric normal VaR; use the stated z-score formula and population standard deviation, retaining full intermediate precision.
[err-00062] helpful=0 harmful=0 :: Do not treat a matching observation count as proof that an archival monthly dataset is correct. Reconcile every selected value against its exact month, row, column, and unit—especially unusually large or boundary-month entries—and independently repeat or cross-check the logarithmic sum before accepting the geometric mean.
[err-00065] helpful=0 harmful=0 :: For Treasury securities ownership tables, verify the requested category against the column header and align each end-of-March year with that column before calculating returns; preserve comma-formatted magnitudes such as 1,012.5 rather than copying a numerically plausible value from a neighboring ownership category or dropping the scale.
[err-00068] helpful=0 harmful=0 :: Do not use a numerically plausible annual-series change after finding the correct historical year. Verify that both endpoint values come from the specifically requested paper-money-in-circulation row and represent end-of-year observations.
[err-00073] helpful=0 harmful=0 :: Do not interpret a request for the percentage attributed to a category across several months as a change in share. Use all requested monthly observations in the numerator and denominator; calculate an endpoint percentage-point difference only when the wording explicitly asks how the share changed.
[err-00075] helpful=0 harmful=0 :: Do not replace a requested chart with a nearby Treasury table, combined statement, forecast, or differently defined account. A conclusion that no year qualifies must be supported by the complete year-by-year comparison from the exact chart.
[err-00077] helpful=0 harmful=0 :: When overlapping bulletins provide the same monthly series, do not calculate competing candidate datasets or introduce an unsupported alternate transcription. Reconcile the exact requested row, all month labels, and each value across the editions first; only then perform the statistic on the single confirmed series.

# Animation Workshop Evolver

A prompt-and-configuration method for the animation-workshop architecture. No MWM lifecycle, pinned skills, world-model facts, or open-case maintenance is loaded. It develops concrete methods, adaptable source and integration examples, records assumptions and scoped preferences, and can request bounded visual trials when a renderer is bound.

Usage: `harnessadapter evolve --architecture animation-workshop --evolver animation-workshop --learning-material PATH --model gpt-5.6-sol --reasoning-effort high --output OUTSIDE_CHECKOUT`.

Preview requests require an explicitly bound external renderer. Requests are snapshotted by the broker; results are read-only observations. This repository's autonomous experiment driver uses the Codex in-app browser for rendering, not native Chrome inside the learner sandbox. A request alone is not a completed visual check.

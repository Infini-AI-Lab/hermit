# harness2 template

The execution harness of Harness² as an adapter: four always-on files and on-demand skills, rendered into
`ADAPTER.md`. Trained by the `harness2` Evolver (`evolver.name: harness2`); any other Evolver that edits the
component files and renders `ADAPTER.md` works too. `harness2.yaml` declares the surface: this template renders
skills inline, for an acting agent that reads only `ADAPTER.md`.

The world model's MEMORY: one entry per fact about this
environment, reached by topic. Every entry carries a `brief:` line (300
chars max, written fresh, not a truncation): hosts see a catalog of all
briefs, newest edit first, and read a full entry by its id — the brief
is what a host uses to decide whether the entry is worth reading, and
editing an entry (its brief included) moves it up the catalog.
Reached by topic: the briefing routes here, and file names are the index —
kebab-case topic words a future reader would guess. Shared spine: first line
routes; scope, last_confirmed_t, derived_from in the header. Underscore-prefixed
files are not part of the model.

## Procedure

Six self-checks, in order, before an answer is committed:

1. Name the vintage: which bulletin file the row comes from, and compare it
   with the latest bulletin carrying the same row.
2. State the units from the table caption (millions vs billions, fiscal vs
   calendar year, percent vs percentage points) before using a number.
3. Count the extracted cells before computing with them.
4. Write the chosen convention next to the number (which rows, which
   formula, which year basis).
5. Round last: full precision through the computation, rounding only the
   committed answer to what the question asks.
6. Commit as soon as a candidate number exists. Apply only lessons whose
   `status:` line reads `verified` (a `candidate` lesson is an unchecked hint)
   and mention the [L-id] of every lesson you apply.
